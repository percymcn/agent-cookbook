# inference.sh

Run 150+ AI applications in the cloud via the [inference.sh](https://inference.sh) platform. One API key for everything.

## When to use

- Generating images (FLUX, Reve, Seedream, Grok Imagine, Gemini).
- Generating video (Veo, Wan, Seedance, OmniHuman, HunyuanVideo).
- Running LLM inference (Claude, Gemini, Kimi, GLM-4 via OpenRouter).
- Web search (Tavily, Exa).
- 3D generation (Rodin).
- Audio/TTS/voice cloning.
- Twitter/X social automation.

## Key tool

- **`infsh`** — the inference.sh CLI, invoked via terminal.

## Notes

- Requires a valid inference.sh API key configured in the environment.
- All compute runs remotely; no local GPU required.
- Check credit balance before large batch jobs.
