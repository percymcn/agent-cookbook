# GIFs

Skills for searching, downloading, and working with GIF and short-form animated media.

## When to use

- Searching for GIFs by keyword or topic.
- Downloading or embedding animated media in messages, documents, or web pages.
- Converting between animated formats (GIF, WebP, APNG).

## Notes

- GIF search may require API keys for services like Giphy or Tenor depending on sub-skill.
- Be mindful of licensing when using GIFs in commercial or published content.
