### AI Content Production Pipeline
1. **Script**: Claude generates scripts from trending topics / hooks
2. **Voice**: ElevenLabs or PlayHT ($22-48/mo)
3. **Visuals**: Runway, Pika, stock footage, screen recordings
4. **Edit**: CapCut (free) or auto-edit tools
5. **Schedule**: Blotato handles multi-platform distribution
6. **Engagement**: Auto-replies via Blotato comment features
